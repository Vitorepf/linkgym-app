# Os 82, um a um — ideia, estratégia, fluxo, rede, problema

21 ago 2026. Companheiro de `destilacao-mobbin-82-social.md` (mapa, gramática, ancestrais). Este arquivo é o pedido do fundador: **entender cada um**.

Filtro: iOS · Social Networking · Most popular · 82 apps. Tagline = Mobbin. Ordem = a listagem.

Como ler um card:

- **Ideia** = o contrato com o usuário (uma frase).
- **Estratégia** = como pensaram que isso vira rede, não feature.
- **Fluxo** = o caminho que a mão faz (abrir → gesto → o que sobra).
- **Rede** = como o grafo nasce (follow, match, servidor, lugar, objeto, anônimo).
- **Acerto** = o que a função acertou um dia.
- **Problema** = o que falhou *neste* produto (não “o que o Link não quer”). Todo mundo tem um. Instagram também.
- **Link** = herda / recusa. Sem meia-palavra.

Pixel desta sessão só onde o card cita URL do Mobbin. O resto é produto conhecido + o que a pesquisa desta rodada fechou (mortes, aquisições, números). Não inventamos tela que não abrimos.

## 1–20

### 1. Instagram — Videos, creators & friends

- **Ideia:** o mundo te vê. Foto, Reels, Stories. Você é o grid.
- **Estratégia:** identidade visual barata + follow + algoritmo For You. Quem posta mais, existe. A rede é audiência, não lugar.
- **Fluxo:** abre no feed → Stories em cima → post/Reels → like/comment raso → DM. Perfil = avatar + números + highlights + grade 3 colunas. [Pixel](https://mobbin.com/screens/fd46bbb4-f06b-4ef9-83aa-461daa667c15).
- **Rede:** follow assimétrico. Você não precisa que o outro aceite. O grafo explode. For You depois come o grafo: o vizinho perde para o criador.
- **Acerto:** identidade imediata. Qualquer um entende o perfil em 1s.
- **Problema:** o diálogo morre. Like não é conversa. Comment é performance. Stories viraram o produto e o post virou arquivo. Quem copia o grid já perdeu: a pose é dele.
- **Link:** recusa feed, Stories, grid, follower. Rouba zero.

### 2. Tinder — Meet new people & date singles

- **Ideia:** quem combina comigo, agora, por carta.
- **Estratégia:** mercado de atenção. Escassez falsa (um card por vez). Match só é mútuo. Monetiza ansiedade (Boost, Super Like).
- **Fluxo:** carta full-bleed → pills (Has Bio, Art, “Matched 3 Preferences”) → X / Star / Heart / Bolt → se match, chat. [Pixel](https://mobbin.com/screens/edd51a54-162e-4ecf-a044-97a9ed07b3df).
- **Rede:** grafo zero até o match. Depois é inbox. Não há publicação. Não há imagem pública que acumula.
- **Acerto:** a carta empilha prova (foto + idade + pills). Decisão em 1s.
- **Problema:** sem objeto compartilhado. A pessoa é o produto. Swipe cansa. Chat depois do match é o mesmo deserto de sempre. Academia não é “quem combina”; é quem está a 20 metros.
- **Link:** recusa swipe. Carta de **prova** só se o verso for Feito, não cara.

### 3. Clubhouse — Join live voice chats

- **Ideia:** sala de voz ao vivo. Você entra, ouve, levanta a mão.
- **Estratégia:** FOMO de convite (2020) + rooms públicas + “seus amigos estão falando”. A rede seria o grafo de quem está *agora* na sala.
- **Fluxo:** lista de rooms → Join → ouvir → raise hand → falar. Sem post. Sem perfil que acumula ato.
- **Rede:** efêmera. Você é a sala, não a conta. Quando o amigo não está, o app é um rádio de estranhos.
- **Acerto:** presença ao vivo sem câmera. Baixo atrito para “estar junto”.
- **Problema:** sem rastro não há identidade. Post-covid o fundador admitiu: ficou difícil achar os amigos e caber conversa longa no dia. Downloads caíram 86% em 2022. Twitter Spaces copiou a função *dentro* de uma rede que já existia. Valuation de $4B, depois corte de metade do time (2023). [Clubhouse layoffs](https://www.cnbc.com/2023/04/27/clubhouse-layoffs-app-reached-4-billion-valuation-during-pandemic.html) · [e-mail dos founders](https://blog.clubhouse.com/april-27-2023/) · [The Verge, houses](https://www.theverge.com/2022/8/9/23298097/clubhouse-houses-panera-sonic-branding-prx-productions-goat-rodeo).
- **Link:** recusa voice. Raid é Zap. Presença sem rastro não constrói Rei da unidade.

### 4. Discord — Talk, play, hang out

- **Ideia:** um lugar (servidor) com papéis e canais, não um feed mundial.
- **Estratégia:** o produto é a casa. Invite + roles + categorias. Quem você é some no servidor. A rede cola porque o grupo *já* existia (game, turma, fandom).
- **Fluxo:** lista de servers → banner + members → Channels & Roles → `#welcome` / `#general` / voice. [Pixel Design Buddies](https://mobbin.com/screens/e0d2e713-f400-407c-b0ce-bbc1c617eca7).
- **Rede:** join de servidor, não follow. Hierarquia (admin/mod/role) é classificação social.
- **Acerto:** power vs CrossFit como **sala**, não tag de Tinder. Guerra de clã cabe aqui.
- **Problema:** chat eterno. Servidor de 80 mil já é cidade. Explore de servidor vira shopping. Quem não fala some. Sem objeto de prova, o “RPG” é cargo de admin.
- **Link:** herda papel + canal da turma. Recusa chat e servidor mundial.

### 5. WhatsApp — Simple, reliable, private messaging

- **Ideia:** mensagem chega. Sem plateia.
- **Estratégia:** o telefone *é* a identidade. Grafo = agenda. Status é Stories menor. No Brasil ganhou o país inteiro.
- **Fluxo:** lista de conversas → bolha → mídia / call. Grupos. Status. Zero perfil-portfólio.
- **Rede:** simétrica, íntima, já no SIM. Não se “descobre” gente. Se avisa gente.
- **Acerto:** o único chat que o aluno já abre. Raid que não termina aqui é arrogância.
- **Problema:** não constrói imagem pública. O grupo some. Não há recibo. Não há Rei. Caos.
- **Link:** recusa reimplementar. Bora → Zap. O app é o *motivo* do Zap, não o container.

### 6. Fable — Books & TV

- **Ideia:** clube de história (livro / série) com diário de leitura.
- **Estratégia:** objeto compartilhado (o livro) + salas spoiler-free + stats (meta anual, streak, wrap). Letterboxd de página, com clube. [Site](https://fable.co/).
- **Fluxo:** logar progresso → review / tag / spice → sala do capítulo → clube. Feed de listas.
- **Rede:** clube (join) + follow de leitor. A tribo fala a língua do objeto.
- **Acerto:** classificação emerge do diário (gênero, meta, streak). Tribo com vocabulário.
- **Problema:** streak diário de página é Duolingo de livro. For You de TBR vira descoberta, não clube. TV dilui. Sem lugar físico.
- **Link:** tribo + diário sim. Streak diário e clube de conteúdo não.

### 7. Bump — Hang with friends IRL

- **Ideia:** mapa dos seus. Quem está onde, agora. Time do Zenly.
- **Estratégia:** presença em tempo real vira motivo de sair. Shake para “bump”. Scratch map. Chat no mapa. [App Store](https://apps.apple.com/us/app/bump-go-out-hang-out/id6471519217).
- **Fluxo:** mapa → amigo no bar → rota / Uber / ETA no lockscreen → hang. Chat se quiser.
- **Rede:** amigos + escola/frat. Dual, íntimo, geográfico.
- **Acerto:** IRL é o produto. “Quem está a 20 m” é o que academia já tem na catraca.
- **Problema:** sem prova de ato. Vigilância lúdica. Scratch map é Pokédex de rua. Chat no mapa compete com Zap.
- **Link:** herda hang / bora. Recusa GPS de amigo e chat.

### 8. TikTok — Videos, music & live streams

- **Ideia:** o próximo vídeo te prende. Você não escolhe a rede; o algoritmo escolhe você.
- **Estratégia:** For You como home. Criador > amigo. Música como cola. Live como extra.
- **Fluxo:** scroll vertical → like / comment / stitch → perfil de creator. Tab Friends é desculpa.
- **Rede:** follow é opcional. O grafo real é o modelo de recomendação.
- **Acerto:** atenção. Distribuição de zero para milhões.
- **Problema:** o pior ancestral possível para academia. Lugar some. Amigo some. Prova vira trend. Quem “é” o app é o criador, não o aluno da Bueno.
- **Link:** recusa. Inteiro.

### 9. X — Breaking news & social media

- **Ideia:** falo agora, o povo responde *neste* post.
- **Estratégia:** texto curto + reply + repost = conversa pública. Depois: For You, Communities, monetização de briga.
- **Fluxo:** composer → tweet → thread de replies → quote. [Pixel](https://mobbin.com/screens/d566d851-d002-453a-8058-ea9ace35a7d4).
- **Rede:** follow assimétrico + Communities (Admin/Mod). Grafo de ideia, não de lugar.
- **Acerto:** o Twitter antigo *é* o diálogo na publicação. Ancestral honesto do pedido.
- **Problema:** For You come o grafo. Virality premia o pior. Badge de mod é RPG falso. DM ao lado do post desvia o diálogo.
- **Link:** herda reply no objeto. Recusa For You, quote, Communities de polícia.

### 10. Peanut — Fertility pregnancy motherhood

- **Ideia:** mulheres no mesmo estágio de vida se acham.
- **Estratégia:** classe = condição (grávida, postpartum). Grupos com língua própria. Não “social genérico”.
- **Fluxo:** estágio → grupos → post / pergunta → amizade.
- **Rede:** tribo por estado, não por follow mundial.
- **Acerto:** linguagem nativa. A 18h / o power / o Hyrox são isto: classe, não bio.
- **Problema:** conteúdo de vida, não de ato no rack. Fora do produto. O modelo é que importa, não o tema.
- **Link:** herda modelo de tribo. Recusa o conteúdo.

### 11. Snapchat — Share the moment

- **Ideia:** mando agora, some. Amigo, não plateia.
- **Estratégia:** 1:1 efêmero + Stories + Map + streak. A rede é intimidade performática. Streak é a corrente.
- **Fluxo:** câmera abre primeiro → snap → Stories. Map. Spotlight (For You deles).
- **Rede:** amigo simétrico no começo; Spotlight virou TikTok.
- **Acerto:** instantâneo. Câmera como home (o rack deveria ser “número”, não câmera).
- **Problema:** streak diário gera ansiedade e mentira. Map é zenly dentro. Spotlight traiu o “amigo”.
- **Link:** recusa Stories, streak, Map, Spotlight.

### 12. Linktree — Link in bio creator

- **Ideia:** o perfil é um índice de destinos.
- **Estratégia:** Instagram não deixa N links. Linktree vende o corredor. Identidade = lista.
- **Fluxo:** tap no link da bio → lista → sai do app.
- **Rede:** nenhuma. É porta, não grafo.
- **Acerto:** honestidade. O perfil-índice não finge que é conversa.
- **Problema:** zero ato, zero diálogo, zero lugar. Somos o destino, não o corredor do Instagram.
- **Link:** recusa.

### 13. LinkedIn — Find jobs, insights and news

- **Ideia:** eu sou meu trabalho. Headline + histórico + skill.
- **Estratégia:** CV público + grafo profissional (connection) + feed corporativo para reter. All-star = quest de preencher perfil. [Pixel](https://mobbin.com/screens/9920d587-49eb-4d75-9681-ec11117580ab).
- **Fluxo:** perfil (headline, Experience, Skills, Featured) → Start a post → reactions. Message.
- **Rede:** connection (quase simétrico) + follow de empresa. Depois o feed come o CV.
- **Acerto:** uma linha classifica (“UX Analyst at Mobbin”). Skill com assessment é stat verificado.
- **Problema:** All-star é farm. Feed virou Twitter de gravata. Reaction não é diálogo. 500+ connections é Instagram profissional.
- **Link:** headline + skill do rack. Recusa All-star e feed.

### 14. Nextdoor — Neighborhood network

- **Ideia:** a rua é o grafo.
- **Estratégia:** verifica endereço. Feed da vizinhança. Confiança local, fofoca inclusa.
- **Fluxo:** post da rua → comentário → grupos / crime / lost dog.
- **Rede:** lugar primeiro, pessoa depois. Quem mora perto vê, mesmo sem follow.
- **Acerto:** o grafo é geográfico. Unidade é prima da rua.
- **Problema:** fofoca, pânico, política de condomínio. Sem prova de ato. “Vizinho” ≠ turma das 18h.
- **Link:** herda grafo de lugar. Recusa feed de rua.

### 15. Telegram — Fast. Secure. Powerful.

- **Ideia:** chat rápido + canal de um para muitos.
- **Estratégia:** velocidade e supergrupo. Canal é broadcast disfarçado de chat.
- **Fluxo:** chat / canal / bot. Quase zero perfil.
- **Rede:** número + username. Supergrupo = Discord sem role.
- **Acerto:** canal ≠ diálogo (honesto quando assume broadcast).
- **Problema:** não constrói imagem. Supergrupo é cidade. No Brasil perdeu para o Zap.
- **Link:** recusa.

### 16. BeReal. — Share real moments, no filters

- **Ideia:** todo mundo fotografa o mesmo minuto. Sem filtro.
- **Estratégia:** sincronia forçada = prova do instante. Dual camera. RealMoji. Amigos, não For You (no começo).
- **Fluxo:** notificação → 2 min → foto frente/trás → feed dos que postaram → RealMoji / comment. Perfil vazio é buraco. [Pixel](https://mobbin.com/screens/72d3854d-97be-4541-a917-64a0100ce65d).
- **Rede:** amigos. Depois: Discovery, late posts, teatro de “real”.
- **Acerto:** perfil sem ato é honesto (“Fill in what's missing”). Prova no tempo.
- **Problema:** obrigação diária. RealMoji vira pose. Quem posta late quebra a tese. Não é ato; é instante.
- **Link:** prova no tempo sim. Câmera diária não.

### 17. Patreon — Exclusive creator communities

- **Ideia:** pago para entrar na casa do criador.
- **Estratégia:** teto + tiers. Comunidade como recompensa da assinatura.
- **Fluxo:** pagar → feed / posts / Discord do creator.
- **Rede:** fã → criador. Assimétrica, paga.
- **Acerto:** teto. Comunidade com porta.
- **Problema:** paywall de pertencimento. O aluno já pagou a academia. Não paga de novo para ver a turma.
- **Link:** recusa. Teto do grupo é vaga, não cartão.

### 18. Facebook — More together

- **Ideia:** todo mundo que você já conheceu, num feed.
- **Estratégia:** grafo real (escola, família) + Groups + Events. O feed comeu o grafo.
- **Fluxo:** feed → Groups / Events / Marketplace. Perfil-arquivo.
- **Rede:** amigos simétricos no começo. Depois Pages, follow, Reels.
- **Acerto:** Groups e Events ainda funcionam. IRL tem palco.
- **Problema:** o feed morreu de ruído e parente. Reels é TikTok pior. A rede que importava (turma, evento) ficou enterrada.
- **Link:** evento / grupo. Recusa feed.

### 19. YouTube — Videos, music and live streams

- **Ideia:** o vídeo longo é o objeto. Inscreve no canal.
- **Estratégia:** creator + algoritmo + ads. Comunidade é comment sob o vídeo.
- **Fluxo:** watch → like / comment / subscribe. Live. Shorts (TikTok).
- **Rede:** subscribe assimétrico. Comment não é rede de lugar.
- **Acerto:** prova longa (aula, recap) tem casa.
- **Problema:** não é academia social. Shorts traiu o objeto. Comment é plateia.
- **Link:** recusa como rede. Aula do personal não mora aqui.

### 20. Messenger — Text, audio and video calls

- **Ideia:** o chat do Facebook, fora do Facebook.
- **Estratégia:** inbox da maior rede do mundo. Depois: Rooms, Stories, shops.
- **Fluxo:** chat. Call. Igual Zap com cromo Meta.
- **Rede:** grafo do Facebook.
- **Acerto:** atalho. Útil onde o FB ainda é a agenda.
- **Problema:** não constrói imagem. No Brasil o Zap já ganhou.
- **Link:** recusa.

## 21–40

### 21. zenly — The app that maps your world

- **Ideia:** o mapa *é* a rede. Seus amigos no mundo, ao vivo.
- **Estratégia:** presença contínua, bateria, ghost mode. Dezenas de milhões, sobretudo Europa/Ásia.
- **Fluxo:** mapa → bolha do amigo → hang.
- **Rede:** amigos + localização. Sem follow mundial.
- **Acerto:** “quem está perto” sem pedir post. Ancestral de Bump.
- **Problema:** Snap comprou (>$200M) e matou em 2022 *mesmo crescendo*, para proteger o Snap Map e porque não achou receita. Não vendeu a terceiros de propósito. [TechCrunch](https://techcrunch.com/2022/09/01/zenly-is-still-hugely-popular-so-whys-snap-shutting-it-down/). Vigilância. Sem prova de ato.
- **Link:** lugar sim. Mapinha de amigo não.

### 22. Reddit — Social forum & community chats

- **Ideia:** o assunto tem casa (`r/`). O post vive na casa, não no seu perfil.
- **Estratégia:** comunidade > indivíduo. Karma é o preço. Anonimato liberta e apodrece.
- **Fluxo:** home / r/ → post → árvore + upvote + flair. [Pixel](https://mobbin.com/screens/fa893128-b9da-4820-b136-89efd151ac0c).
- **Rede:** join de sub. Perfil fraco de propósito. Chat depois foi enxerto.
- **Acerto:** diálogo com memória. Tribo. Flair = classificação.
- **Problema:** home mundial. Karma vicia. Anonimato + briga. Moderação é polícia. Péssimo como home do rack.
- **Link:** árvore no Feito da *turma*. Sem karma, sem r/worldnews.

### 23. Yubo — Match text talk. Be real now

- **Ideia:** amizade / dating Gen Z por live e match, “sem algoritmo”. [Site](https://www.yubo.live/).
- **Estratégia:** presença ao vivo + swipe leve. Conversa agora, não perfil de mercado.
- **Fluxo:** live / match → chat / video. Age gate depois (o problema veio antes).
- **Rede:** desconhecidos. Grafo de sessão, não de lugar.
- **Acerto:** “agora” sem plateia de Instagram.
- **Problema:** random + menor. Safety é o produto de verdade. Zero prova, zero unidade.
- **Link:** recusa.

### 24. Gas — See who likes you

- **Ideia:** elogio anônimo na escola. “Quem gostou de você.”
- **Estratégia:** Nikita Bier (TBH → Facebook → morto). Ego + anonimato + colégio. Discord comprou (jan 2023) por time, não por produto.
- **Fluxo:** prompt → voto anônimo → revelação parcial → “veja quem”.
- **Rede:** escola. Anônima. Sem publicação.
- **Acerto:** o colégio *é* o grafo (unidade escolar).
- **Problema:** veneno social. Pico nov 2022 (3,1M downloads no mês), depois 2.900. Discord fechou em 7 nov 2023. TBH já tinha morrido do mesmo jeito. [TechCrunch](https://techcrunch.com/2023/10/19/discord-kills-gas-anonymous-compliments-app-bought-nine-months-ago/).
- **Link:** recusa. Anônimo + ego ≠ Tá pago.

### 25. Lemon8 — Lifestyle community app

- **Ideia:** Xiaohongshu no Ocidente. Grid de “como viver” (moda, comida, wellness).
- **Estratégia:** ByteDance copia o playbook da China (como TikTok copiou Douyin). Hedge político + creators pagos no lançamento. [TechCrunch](https://techcrunch.com/2023/04/07/lemon8-bytedance-copy-from-china/).
- **Fluxo:** grid editorial → save → For You de lifestyle.
- **Rede:** follow de creator + algoritmo. “Zhongcao” = vontade de comprar.
- **Acerto:** relevância > glamour (na tese chinesa).
- **Problema:** no Ocidente nasceu Instagram+Pinterest com creator subsidiado. Pose. E-commerce. Sem lugar.
- **Link:** recusa.

### 26. Behance — Photography & design community

- **Ideia:** o portfólio *é* a rede. Projeto, não pose de stories.
- **Estratégia:** Adobe. Appreciations + follow de projeto. Identidade = o que você fez (criativo).
- **Fluxo:** grid de projeto → case → follow / appreciate.
- **Rede:** follow profissional de trabalho, não de cara.
- **Acerto:** tese 3 criativa. Ato visível.
- **Problema:** follower de arte. Grid vira pose se o “projeto” for selfie. Sem lugar.
- **Link:** grid só se for **prova** (Feito), não moodboard.

### 27. Hypelist — Create & share lists

- **Ideia:** eu sou minhas listas (lugares, livros, gosto).
- **Estratégia:** gosto explícito compartilhado. Follow da lista.
- **Fluxo:** criar lista → share → follow.
- **Rede:** objeto-lista. Fraca.
- **Acerto:** lista é classificação honesta (“estes 8 filmes”, “estes 8 movimentos”).
- **Problema:** sem ato. Vibe curada. Não prova que foi.
- **Link:** lista de PRs / ficha. Não vibe.

### 28. Retro — Share photos worth remembering

- **Ideia:** diário semanal de foto com amigos de verdade. Sem algoritmo.
- **Estratégia:** “social, not media”. Likes privados. Postcard físico. Album de grupo. [Play](https://play.google.com/store/apps/details?id=io.lonepalm.retro).
- **Fluxo:** escolhe foto da semana → amigos veem → recap mensal. Chat depois (traiu a tese).
- **Rede:** friend list privada. Dual opt-in.
- **Acerto:** memória, não Stories. Grafo fechado.
- **Problema:** ainda é foto. Sem prova de treino. Chat/álbum compete com Zap. Recap pede Instagram de novo.
- **Link:** recusa como home. Diário sim se o objeto for Feito.

### 29. Mozi — A place for your people

- **Ideia:** não perder o amigo adulto (cidade, viagem, aniversário).
- **Estratégia:** friend model (dual opt-in). Sem feed público, sem follower, sem ads. Cidade, não GPS fino. [App Store](https://apps.apple.com/us/app/mozi-a-place-for-your-people/id6482482498).
- **Fluxo:** sync contacts → connect → Live City / trips → notes privadas.
- **Rede:** círculo íntimo. CRM de amizade.
- **Acerto:** “social, not media”. Grafo escolhido.
- **Problema:** pouca prova. É agenda afetiva. Sem ato compartilhado a turma não compete.
- **Link:** turma, não app de “people”. Recusa CRM de amigo.

### 30. Orb Social — The best Web3 social app

- **Link:** ancestral #1 do perfil. Feito = log. Sem estrela de “gostei”. Sem Popular this week.

### 80. Periscope — Meet people, explore the world

- **Ideia:** ao vivo do bolso. O mundo entra na sua câmera.
- **Estratégia:** live como rede. Corações. Twitter comprou antes do launch (2015).
- **Fluxo:** Broadcast → watchers → heart. Explore lives.
- **Rede:** follow + geo explore. Efêmera.
- **Acerto:** popularizou live no celular.
- **Problema:** Facebook Live copiou *dentro* de uma rede maior. Twitter pôs live no próprio app (2016). Uso caiu. Shut 31 mar 2021, “unsustainable maintenance-mode”. [The Verge](https://www.theverge.com/2021/3/31/22360717/periscope-shut-down-twitter-live-streaming). Live sem casa morre; live-como-feature sobrevive no incumbente.
- **Link:** recusa live. Recibo, não broadcast.

### 81. Bluesky Social — Social media as it should be

- **Ideia:** Twitter com protocolo. Você leva o grafo.
- **Estratégia:** AT Protocol + starter packs. Grafo escolhido (custom feed) contra For You único.
- **Fluxo:** skeet → reply. Starter pack → follow em lote.
- **Rede:** follow + pack. Protocolo promete portabilidade.
- **Acerto:** grafo escolhido. Starter pack = “entre pela 18h”, não pelo For You.
- **Problema:** ainda vira Twitter (briga, viral, celeb). Protocolo não resolve lugar. O aluno não quer DID.
- **Link:** grafo escolhido = unidade. Recusa protocolo.

### 82. Elbi — Where loves unlocks change

- **Ideia:** bondade / causa como rede. “Love unlocks change.”
- **Estratégia:** gesto kind + donate / impacto. Identidade moral.
- **Fluxo:** ação de causa → share.
- **Rede:** causa. Grafo de virtude.
- **Acerto:** nenhum para academia.
- **Problema:** irrelevante. Teatro moral. Sem unidade, sem ato, sem turma. Está nos 82 porque a Apple enfia “social” em tudo que tem gente.
- **Link:** recusa.

## O que os 82 ensinam quando você lê os problemas, não os logos

Cinco mortes se repetem. Não são 82 mortes diferentes.

| Morte | O que acontece | Quem |
|---|---|---|
| **A incumbente come a feature** | A função viva vai para o app que já tem o grafo | Clubhouse → Spaces; Periscope → Twitter/FB Live; Houseparty → Zoom/Rooms; zenly → Snap Map; Breaker → Spaces; Vine → IG/Snap |
| **Acqui-hire / proteção** | Compram o time ou matam o concorrente interno | Gas (Discord), zenly (Snap), Houseparty (Epic), Breaker (Twitter), Byte (sozinho, sem grafo) |
| **Métrica fictícia** | “Grupo” sem gente no prédio | IRL (95% bot, SoftBank processa) |
| **Grafo errado** | Follow mundial / For You / random / anônimo | Instagram, TikTok, X hoje, Yubo, Monkey, Azar, Yik Yak, Gas |
| **Sem rastro / sem ato** | Presença que some quando a rua abre | Clubhouse, Houseparty, Airtime, Sonar, BeReal-como-instante |

Três máquinas sobrevivem e são as únicas que o RPG do fundador pode herdar:

1. **Diário que vira imagem** (Letterboxd, Fable-como-caderno, Swarm-sem-coin).
2. **Casa com papel** (Discord pequeno, Mammoth-instância, Digg-Join, Peanut-tribo).
3. **Diálogo no objeto** (Twitter antigo, Threads, Reddit-da-casa).

Tudo que for chat, swipe, Stories, widget de vigilância, voice sem rastro, token, quiz, live, cadáver — os 82 já pagaram a conta.
